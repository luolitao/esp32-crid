基于您分享的 GitHub 仓库 [luolitao/esp32-crid](https://github.com/luolitao/esp32-crid)，这是一个基于 ESP32 微控制器的**开源无人机远程识别（Remote ID, 简称 RID）工具系统**。它同时具备了无人机 RID 信号的扫描接收（Scanner）**与**模拟发射（Simulator）功能。

以下是对该项目的详细分析与总结：

---

## ## 项目核心架构与功能

该项目基于 **ESP-IDF 6.0.1** 开发框架，主要针对 **ESP32-S3** 芯片进行部署，同时也向下兼容 ESP32-C3 等模组。项目采用模块化设计，通过构建指令切换编译为“接收器”或“发射器”。

### 1. 接收器模式 (Scanner / `main_rx`)

通过 Wi-Fi 的混杂模式（Sniffer）抓取空中的无线数据包，并对无人机发出的 Remote ID 信号进行实时解码。

* **多标准兼容**：支持国际主流的 **ASTM F3411-22**、**ASD-STAN prEN 4709-002** 标准，同时支持中国的 **GB 42590-2023（国标）**。
* **自动协议识别**：解析器通过 Message Pack 的首字节（ASTM 为 `0xF2`，国标为 `0xF1`）自动识别并切换解析逻辑。
* **双端口输出设计**：
* **数据端口 (UART1 / GPIO17)**：纯净输出解析后的无人机数据（JSON 格式）。
* **调试端口 (USB CDC)**：输出系统启动、告警、错误及解码诊断信息。


* **动态追踪**：内置线程安全的无人机追踪表（Tracker），支持新设备发现、数据定期更新、活跃状态监视以及 5 分钟无信号自动超时清理。

### 2. 发射器模式 (Simulator / `main_tx`)

用于模拟无人机广播 Remote ID 信号。

* **轨迹模拟**：支持巡游路径模拟（Patrol），可模拟无人机的速度、航向和坐标。
* **完全合规的帧构造**：模拟广播包含 Message Counter 和 Packed 消息的 Beacon 帧，Vendor IE（厂商特定厂商信息元素）完全符合标准。

## ## 技术参数与数据格式

项目在协议实现上非常规范，统一了无线电底层的关键参数：

| 参数 | 设定值 / 说明 |
| --- | --- |
| **OUI（组织唯一标识符）** | `FA:0B:BC`（ASTM 与中国国标统一使用） |
| **Vendor Type** | `0x0D` |
| **Wi-Fi 信道** | Channel 6（2.437 GHz） |
| **广播频率** | 1 Hz（每秒 1 次） |
| **IE ID** | 221（Vendor Specific） |

### 数据输出示例 (JSON)

接收端解析出的数据以单行 JSON 格式输出，极大地方便了下游系统的集成。其字段涵盖了无人机的全方位动态与静态信息：

* **基础信息**：MAC 地址、RSSI（信号强度）、协议类型（ASTM/国标）、消息计数。
* **Basic ID**：无人机序列号（Serial Number）、设备类型（如多旋翼/直升机）。
* **Location（位置）**：经纬度、气压高度、地理高度、起飞相对高度、航向、水平/垂直速度以及位置精度。
* **静态/管理信息**：操作员位置、自我描述（如 "Drone #1"）、操作员 ID（Operator ID）以及认证信息（Auth）。

## ## 配套工具

项目在 `tools/` 目录下提供了一个基于 Python 的上位机工具 **`json_monitor.py`**。

* **多模式查看**：支持仅查看无人机数据 (`data`)、仅查看系统调试 (`debug`)、仅查看去重后的无人机静态信息 (`static`) 或全部捕获 (`all`)。
* **会话摘要**：在按下 `Ctrl+C` 退出时，脚本会自动输出一份完善的统计摘要，包括运行时长、捕获的无人机总数、解码失败率以及每个无人机 MAC 的最后活跃快照。

## ## 项目总结与应用场景

`esp32-crid` 是一个低成本、高集成度且紧跟最新国内外行业标准的无线电监测/仿真项目。

**核心优势：**

1. **硬件成本极低**：基于高性价比的 ESP32-S3/C3 芯片，相比于昂贵的专用无线电监测设备，极大降低了开发和部署门槛。
2. **数据极其友好**：全 JSON 序列化输出和双端口分离设计，让它可以非常方便地挂载到树莓派、PC 或云端服务器作为边缘数据采集探针。
3. **合规性高**：同时打通了国际 ASTM 与中国最新国标（GB 42590-2023），具有很强的实用落地价值。

**典型应用场景：**

* **低空安全监控**：部署在特定空域（如机场周边、敏感园区）周围，作为低成本的无人机侦测探针。
* **无人机研发与测试**：利用发射器（Simulator）功能，在实验室环境下模拟复杂的无人机 Remote ID 广播，用于测试地面站或监管系统的接收能力。
* **无线电爱好者与教学**：用于学习 Wi-Fi 混杂模式抓包（Sniffer）、自定义 Beacon 帧伪造以及 OpenDroneID 协议解析。
